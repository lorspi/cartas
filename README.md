## Sobre el proyecto

Cartas que quedan nace de una idea sencilla: hay pensamientos que no deberían perderse en el vértigo de las redes ni en el flujo de información que consumimos y olvidamos en minutos.

Es un pequeño archivo de cartas para leer con calma. Textos pensados no para acumular aplausos ni para alimentar debates estériles, sino para acompañar a quien necesita detenerse a pensar sobre el amor, el duelo, la violencia, la fe sin arrogancia, la justicia y el peso de las decisiones cotidianas.

Cartas para pensar. Cartas para recordar. Cartas para quienes vienen después.
